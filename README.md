# נשימת קופסה

אפליקציית ווב סטטית לתרגיל נשימת קופסה (שאיפה · החזקה · נשיפה · החזקה): ריבוע מונפש, הגדרות דפוס, ספירת סבבים, צלילים ורטט, ומצב כהה/בהיר. ניתן להוסיף למסך הבית כ-PWA.

## הרצה מקומית

```bash
python3 -m http.server
```

ואז לפתוח בדפדפן את `http://localhost:8000`.

## פרסום

העלו את תוכן שורש המאגר ל-GitHub Pages (מקור: branch `main`, תיקייה `/`). האפליקציה עובדת גם בלי אינטרנט לאחר טעינה ראשונה.

הפרויקט ללא תלויות חיצוניות — קבצי HTML, CSS ו-JavaScript בלבד.
